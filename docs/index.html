أهلاً بك في واحة

  1. اكتشف مهارة

    ابحث أو فلتر حسب الفئة والمستوى. المهارات الست عينات للتجربة.

  2. حمّل بيانات المهارة

    تنزيل JSON يعمل دون تسجيل. أزرار الحفظ والتعلّم غير مُفعّلة في نسخة Pages.

  3. استخدم التطبيق الكامل

    نسخة الخادم على PromptQL تدعم المحادثات الخاصة والحفظ وGemini؛ Pages لا تستضيف Python أو SQLite.

تطبيق مستقل عن صفحة مراجعة الوثيقة؛ لا يقرأ Google Docs ولا يعدّلها. لا يشغّل الكود أو يحمّل إضافات تنفيذية. تنزيل المهارة يعني تنزيل بياناتها وقالب توجيهها فقط.
