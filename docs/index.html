          مساحتك للتعلّم

          كيف تحب تبدأ؟

          يُنشئ محادثة محفوظة ويضيف المهارة إلى مكتبتك. لا يبدأ طلب AI حتى ترسل رسالتك.

          أهلاً بك في واحة

          1. اكتشف مهارة

            ابحث أو فلتر حسب الفئة والمستوى. المهارات الست عينات للتجربة.

          2. حمّل بيانات المهارة

            تنزيل JSON يعمل دون تسجيل. أزرار الحفظ والتعلّم غير مُفعّلة في نسخة Pages.

          3. اسأل مساعدك الذكي

            من القائمة الجانبية ابدأ محادثة عامة تحفظ على خادم واحة المتصل؛ لا يصل المساعد إلى جهازك أو ملفاتك.

          4. استخدم التطبيق الكامل

            خادم واحة المستقل يدعم المحادثات الخاصة والحفظ وGemini ومساحة عمل الوكيل؛ Pages نفسها لا تستضيف Python أو SQLite.

          تطبيق مستقل عن صفحة مراجعة الوثيقة؛ لا يقرأ Google Docs ولا يعدّلها. لا يشغّل الكود أو يحمّل إضافات تنفيذية. تنزيل المهارة يعني تنزيل بياناتها وقالب توجيهها فقط.
