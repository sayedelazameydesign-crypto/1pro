# إعداد API للواجهة

يبقى `config.json` صالحًا كـJSON مع `api_base` فارغًا إلى أن تظهر عناوين
Render الفعلية. JSON لا يدعم التعليقات، لذا يوجد هذا التوضيح في ملف مجاور
بدل إدخال تعليق يكسر `response.json()` في المتصفح.

## بعد النشر

1. انسخ أصل `waha-site` الفعلي من لوحة Render. لا تفترضه من اسم الخدمة.
2. اضبط `WAHA_ALLOWED_ORIGINS` في `waha-backend` على هذا الأصل فقط، مثل
   `https://<site-host>.onrender.com`، بلا مسار أو `*`.
3. بعد ظهور عنوان `waha-backend`، ضع عنوانه العام في `api_base` بهذا الملف،
   مثل `https://<api-host>.onrender.com`، ثم أعد نشر `waha-site`.

قد ينشر Blueprint الخدمتين في المزامنة نفسها؛ الترتيب أعلاه هو ترتيب
الربط. إبقاء `api_base` فارغًا يمنع الواجهة من استدعاء API قبل ضبط CORS.

يقرأ `app.js` الملف مع `cache: 'no-store'`، ويضيف إعداد Render ترويسة
`Cache-Control: no-store` لهذا المسار حتى لا تتأخر ملاحظة تحديثه بعد النشر.

هذا المجلد عام ويحتوي إعدادات واجهة فقط؛ لا تضع فيه مفاتيح أو أسرارًا.
