كيف تحب تبدأ؟

أهلاً بك في واحة

  1. اكتشف مهارة

    ابحث أو فلتر حسب الفئة والمستوى. المهارات الست عينات للتجربة.

  2. اختر طريقة تعلّم

    شرح، تمرين، أو اختبار. اختر Gemini أو NVIDIA ثم أرسل سؤالك. لكل جلسة موفّر ثابت، ولا يوجد انتقال تلقائي.

  3. اسأل مساعدك الذكي

    ابدأ محادثة عامة من القائمة الجانبية. المساعد لا يصل إلى جهازك أو ملفاتك ولا ينفّذ إجراءات.

  4. ارجع وقت ما تحب

    مكتبتك ومحادثاتك محفوظة بحسابك. تستطيع تنزيل ملف JSON أو حذف محادثة.

تطبيق مستقل عن صفحة مراجعة الوثيقة؛ لا يقرأ Google Docs ولا يعدّلها. لا يشغّل الكود أو يحمّل إضافات تنفيذية. تنزيل المهارة يعني تنزيل بياناتها وقالب توجيهها فقط.
