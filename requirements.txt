# package names only: an `-r backend/requirements.txt` include makes the build fail
# with "could not parse requirements.txt: Error parsing included file", which is what
# kept every deployment red. So the pins are listed here in full.
#
# The same pins live in backend/requirements.txt, which is what Render, CI and local
# setup install. The two are kept identical by
# tests/test_vercel_wrapper.py::RootManifestTests, so a version bump in one file that
# forgets the other fails the suite instead of drifting into production.
#
# Do NOT write psycopg without the [binary] extra: the serverless image has no system
# libpq, and a bare `psycopg==...` resolves to the wheel that needs it at import time.
