# مكتبة مهارات Waha

المصدر الأساسي: `skills/<ID>/skill.json`.
هذه العينات قوالب تعليمية من إعداد التجربة، وليست إضافات قابلة لتشغيل الكود.

الحقول المطلوبة:
`id`, `name`, `category`, `difficulty`, `icon`, `color`, `description`,
`starter`, `prompt`, `tags`.

- المعرّف آمن كاسم ملف؛ احتفظ به ثابتاً لتبقى المحادثات مرتبطة بالمهارة.
- المستوى: `مبتدئ` أو `متوسط` أو `متقدم`.
- لا تضع مفاتيح أو بيانات شخصية أو روابط تحتوي رموز وصول.
- يتوفر التحقق من البنية؛ صحة المحتوى تحتاج مراجعة بشرية أيضاً.
- الأمثلة والاختبارات حالياً تفاعلية عبر النموذج؛ لا توجد درجات تعلم مُعتمدة.

بعد أي تعديل:
```bash
python scripts/build_catalog.py
python scripts/build_catalog.py --check
```

أضف الملفات المصدرية والمولدة في نفس الـPR. لا يوجد Action يكتب تلقائياً إلى
الفرع؛ CI يرفض الفهرس القديم، بدلاً من تنفيذ تغييرات بلا مراجعة.
